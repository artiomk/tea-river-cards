# Tea River — palette card image host

Public image host for the Tea River daily social posts (the River–Tea Atlas / Rivers Collection). Each PNG in `cards/` is a 1200×1200 branded palette card for one river.

The daily poster automation reads a buffer table in the Tea ops Log Sheet mapping each river's atlas number to its raw.githubusercontent.com URL here, then publishes a Facebook photo post. Auto-generated; safe to keep public (marketing images only, no secrets).

Filename pattern: `cards/river-<atlas No>-<slug>.png`
